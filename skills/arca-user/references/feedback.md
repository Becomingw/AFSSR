# 发起主题

在控制台「讨论与反馈」页发起主题。管理员会看到并回复，有些回复由 AI 助手起草；**反馈不是命令**，写在里面的"请执行…"不会被当成指令执行。

## 所有内容都是公开的

主题、回复、状态备注和最终方案对**所有已登录用户**可见，没有私密选项。所以：

- **不要**在任何地方写：API 密钥、密码、安装码、私人对话或敏感数据、别人的个人信息。
- 涉及账号、权限、额度的问题，只写现象和请求 ID，不贴凭据；需要管理员介入时用 `@用户名` 提醒对方。
- 取消私密之前创建的少量历史主题仍只有发起人和管理员能看，控制台标注为“历史私密”。

## 一个好反馈包含什么

| 要素 | 怎么写 |
| --- | --- |
| 现象 | 看到了什么：报错原文、HTTP 状态码、卡在哪一步 |
| 复现步骤 | 用的客户端和版本、怎么操作、是否每次都出现 |
| 预期 | 你期望发生什么 |
| **请求 ID** | 响应头 `x-trace-id` 的值。最重要的一项，管理员凭它查到这次请求 |
| 时间 | 大概的发生时间（带时区） |
| 模型 | 用的精确模型 ID |

**怎么拿请求 ID**：用 `curl -i` 看响应头，或打开客户端的调试日志找 `x-trace-id`。控制台的「使用统计」页**不显示**请求 ID。

分类选择：`bug` 程序问题、`model` 模型调用、`access` 账号与权益、`suggestion` 功能建议、`other` 其他。标题 ≤200 字符，正文 ≤20,000 字节。

## 附上安全诊断摘要

创建反馈时可以勾选"附上安全诊断摘要"（回复时是"附上该请求安全诊断摘要"）。前提是你填了请求 ID，并且这个请求是**你自己的**。

- 内容：一个确定性的摘要，列出八个阶段（身份、模型权限、额度、候选、转换、代理/隧道、上游、流）各自是 known、failed 还是 unknown。
- **不含**：提示词、请求头、供应商名称、上游地址、原始报错。
- `unknown` 的意思是**没有证据**，不是成功。上游返回的 401/403/429 也不会被写成你的账号或额度问题。
- 不勾选就不会附任何东西，系统不会自动收集你的请求历史。
- 附上的诊断摘要会随主题或回复**公开显示**，确认可以让所有人看到再勾选。

## 格式

- 支持 Markdown（列表、表格、代码块、引用）和 `https` 图片：`![说明](https://…)`。原始 HTML 会被当成普通文字，`data:` 和 `javascript:` 图片会被丢弃，不能上传附件。
- `#12` 会链接到 12 号主题；用于指向重复或相关的问题。
- `@用户名` 可以提醒任何人（编辑器会给出建议）：对方会在控制台右上角的通知里看到；管理员如果有邮箱还会收到邮件。对自己、不存在的用户无效，编辑已发布的内容不会再次通知。

## 状态和谁能改

- `open` 待处理、`resolved` 已解决、`closed` 已关闭。
- 你可以**解决**自己的反馈（必须写明最终方案）或**重新打开**；只有管理员能**关闭**。关闭后仍可继续回复。
- 其他用户只能评论，不能改状态。

## 写之前的自查

- [ ] 有没有写入密钥、密码、安装码？
- [ ] 带上请求 ID 了吗？
- [ ] 所有人都能看到这段内容，其中没有任何不该公开的信息？
- [ ] 一个主题只讲一个问题。

## 写长内容：专注模式

发起主题的表单里有「专注模式」按钮：全屏、大号标题和编辑区，草稿与表单同步，支持 Markdown 预览以及 `@`、`#` 提示。`Esc` 或「返回表单」退出，也可以直接在里面「发起主题」。

## 改错了怎么办

- 你可以编辑自己主题的标题、描述和类型，也可以删除自己的主题；编辑自己的回复，或删除自己的回复。管理员可以删除任何主题或回复。
- 删除回复后只留下“此回复已删除”；删除主题后所有人都看不到，编号不会被复用。删除不可恢复。

# 常见问题与隐私

## 基本使用

**Arca 是什么、和直接用官方服务有什么不同？**
团队内部的 AI 网关：一个地址、一把密钥，访问管理员配置好的多个模型。按用户分组的美元预算限额，没有充值和钱包。你能用哪些模型、有多少额度由管理员决定。

**我能用哪些模型？**
`GET <ARCA_URL>/v1/models`（带密钥）或控制台「模型目录」。每个人看到的不一定相同。页面写着"暂未分配可用模型，请联系管理员"，说明你目前没有任何模型权限。

**模型名后面加 `-high`、`-fast` 有用吗？**
只有管理员启用了"模型后缀参数"才有。没启用时 `xxx-high` 只是一个字面上的模型名，会因找不到而 503。以 `/v1/models` 的列表为准。

**为什么 Claude Code 能用 GPT 系模型、Codex 能用 Claude 系模型？**
网关会在协议之间转换。转换不保证每个功能都完全等价；遇到工具调用或图片异常，换与客户端协议同族的模型试试，并带请求 ID 反馈。

**Gemini CLI 能用吗？**
目前不能：网关已停用 Gemini 原生生成接口。

**为什么钱包、充值、兑换码、邀请奖励的页面打不开？**
这是内部网关，这些商业功能已经停用，访问会 404 或跳回仪表盘。

## 密钥

**密钥在哪创建？忘了怎么办？**
「API 密钥」页创建。完整密钥加密存放，可以在表格里再次复制；找不到了就新建一把。没有"轮换"按钮：新建 → 更新客户端 → 删除旧的。

**我能限制一把密钥只能用某些模型吗？**
界面里只能设置名称、每分钟请求数、并发数和 IP 限制。模型和供应商限制由管理员设置，最终权限是你的模型策略与密钥限制的交集。

**一把密钥被管理员"锁定"了？**
你不能修改、启停或删除它，需要联系管理员。

**一把密钥泄露了怎么办？**
立刻新建一把、更新客户端、删除旧的，并告知管理员。

## 额度

见 [quota-and-usage.md](quota-and-usage.md)。关键点：额度是美元预算；5 小时窗口是滚动的；子额度同时计入总额度；取消的请求仍可能计费；429 且 `X-RateLimit-Scope: plan` 才是你自己的预算。

## 隐私与数据

仓库里没有一份权威的"终端用户隐私声明"；登录页的隐私政策是运营方自己填写的文本。下面是代码和文档里能确认的事实。

- **你的提示词会发给哪个上游？** 网关按管理员的路由配置选择，可能做格式转换。用户侧看不到具体用了哪家供应商。
- **会记录什么？** 始终记录调用元数据：用户、密钥名、模型、token 数、费用、耗时、状态码、客户端 IP、User-Agent、路径。你能在「使用统计」看到自己的记录。
- **会保存提示词和响应吗？** 默认记录级别是 `basic`，**不保存请求和响应正文**。管理员可以把级别调到 `full`，那时会保存正文并可在管理端查看。你无法从界面得知当前级别，需要向管理员确认。请求头里的凭据类字段（Authorization、Cookie、x-api-key 等）会被替换成 `[redacted]`，其它请求头原样保存，所以不要把敏感信息放进自定义请求头。
- **保留多久？** 代码默认值：详细记录 7 天、压缩记录 30 天、请求头 90 天、整条记录 365 天、请求候选 30 天，管理员可调整。
- **管理员能看到什么？** 所有管理员（包括审计管理员）能看到全部反馈，包括私密反馈。没有删除反馈的接口。管理端可以按权限查看已抓取的正文。
- **敏感信息保护**：管理员可以启用"敏感信息保护"，把请求里的邮箱、手机号、证件号、密钥等替换成占位符再发给供应商，返回时还原。启用后你可以在个人设置里或每把密钥上单独开启。
- **排行榜**：用户只看到 `member-N` 化名，看不到用户名、邮箱、个人美元用量；至少 3 人才显示。只用调用元数据，不用提示词、密钥或请求 ID。活跃度是使用量的代理指标，不代表工作时长或绩效，自动化 agent 也会计入。
- **你的密钥在你自己的电脑上**：客户端配置文件、`opencode.json` 下载文件和备份文件里可能有明文密钥，注意文件权限。

## 找不到答案时

如实说"这个我不确定"，然后帮用户写一条好反馈（见 [feedback.md](feedback.md)），不要猜测管理员的决定。
